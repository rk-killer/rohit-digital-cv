# Rohit Kumar — 3D Motion Digital CV

A responsive, animated creative portfolio made with a single HTML file and local CV PDF. No build tools needed.

## Run locally 
Open `index.html` in Chrome, Edge or Firefox. Keep `Rohit_Kumar_CV.pdf` in the same folder for the Download CV buttons.

## Publish on GitHub Pages
1. Create a public GitHub repository named `rohit-digital-cv`.
2. Upload `index.html`, `Rohit_Kumar_CV.pdf`, and `README.md` to the repository root.
3. Go to Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Your site will appear at `https://YOUR-USERNAME.github.io/rohit-digital-cv/` after deployment.

## Notes
The visual project covers are abstract original graphics, not examples of completed client deliverables. Replace them with your real showreel thumbnails or videos when available. Animations respect reduced-motion accessibility preferences. Google Fonts requires an internet connection; system fallbacks are included.
